現實生活中的決策往往不只「是與否」。本單元帶你掌握 if...else if...else 與 巢狀 if，處理更複雜的多條件判斷！

    1. if...else if...else 範例：成績等級判斷

    C++ 範例程式碼 (點擊行號觀看說明)

    1#include <iostream>
    2using namespace std;
    3
    4int main() {
    5int score;
    6cout << "請輸入分數 (0-100) : ";
    7cin >> score;
    8
    9// 檢查輸入是否合理
    10if (score < 0 || score > 100) {
    11cout << "輸入錯誤！分數必須在 0 到 100 之間。" << endl;
    12}
    13// 由大到小依序判斷
    14else if (score >= 90) {
    15cout << "等級：A (表現優異)" << endl;
    16}
    17else if (score >= 80) {
    18cout << "等級：B (表現良好)" << endl;
    19}
    20else if (score >= 70) {
    21cout << "等級：C (表現尚可)" << endl;
    22}
    23else if (score >= 60) {
    24cout << "等級：D (及格)" << endl;
    25}
    26else {
    27cout << "等級：F (不及格)" << endl;
    28}
    29return 0;
    30}
    💡 提示：請點擊左側程式碼任意行數，即可查看講義對應的詳細解說！

    邏輯重點與流程圖

    • 順序檢查： 程式由上往下依序測試條件，滿足第一個條件即執行該區塊。
    • 命中即跳出： 執行完畢後會直接跳過後續所有 else if 與 else。
    • 預設備用： 若全不成立，最後由 else 自動接管。

    2. 巢狀 if (Nested if) 範例：門票票價計算

    C++ 範例程式碼 (點擊行號觀看說明)

    1#include <iostream>
    2using namespace std;
    3
    4int main() {
    5int age;
    6char hasStudentCard;
    7
    8cout << "請輸入您的年齡: ";
    9cin >> age;
    10
    11// 第一層 if：先判斷年齡是否符合基本票價條件
    12if (age >= 12 && age < 65) {
    13cout << "請問是否有學生證? (y/n): ";
    14cin >> hasStudentCard;
    15
    16// 第二層 if (巢狀)：根據是否有學生證給予不同折扣
    17if (hasStudentCard == 'y' || hasStudentCard == 'Y') {
    18cout << "符合學生優惠！門票價格為：150 元" << endl;
    19} else {
    20cout << "一般成人票，門票價格為：250 元" << endl;
    21}
    22} else {
    23// 未滿 12 歲或 65 歲 (含) 以上直接享有特惠票
    24cout << "符合兒童/敬老特惠！門票價格為：100 元" << endl;
    25}
    26return 0;
    27}
    💡 提示：點擊程式碼各行，拆解「分層過濾 (Outer & Inner)」邏輯。

    巢狀判斷流程圖

    先通過「主要條件（外層）」的篩選，才會進一步進入「次要條件（內層）」繼續檢查。

    graph TD Start([開始]) --> Outer{12 <= age < 65 ?} Outer -- 否 (未滿12或>=65) --> Dis[100元 兒童/敬老特惠] Outer -- 是 --> Inner{有學生證? y/Y} Inner -- 是 --> Stu[150元 學生優惠] Inner -- 否 --> Adult[250元 一般成人票]

    動手做練習 (1 & 2)

    練習 1：三角形判斷填空

    請按按鈕對照填空答案 (A ~ E)：

    A: using namespace std;
    B: a <= 0 || b <= 0 || c <= 0
    C: a + b <= c
    D: sum_sq == c_sq
    E: sum_sq > c_sq

    答案解析：

    A: using namespace std;

    B: a <= 0 || b <= 0 || c <= 0 (檢查邊長合法性)

    C: a + b <= c (兩邊之和須大於第三邊，反向條件)

    D: sum_sq == c_sq (畢氏定理：直角)

    E: sum_sq > c_sq (畢氏定理：銳角)

    動手做練習 (3 & 4)

    練習 3：閏年判斷程式 Code Review (4處錯誤)

    請找出語法與邏輯錯誤：

    1. 語法錯： std::cin >> year 結尾缺少分號 ;

    2. 比較運算錯： year % 400 = 0 為賦值，應為 ==

    3. 邏輯條件順序錯： 較嚴格的條件（% 400, % 4000）放在後面會被第一個 % 4 == 0 提前攔截。

    4. 閏年定義規則錯： 4000的倍數應為平年，400的倍數應為閏年。

    練習 4：象限判斷邏輯

    引導學生思考：透過多重分支遞進，先排除了點在原點與兩軸（x==0 或 y==0）的情況。

    最後剩餘的條件自動進入四大象限判斷！
