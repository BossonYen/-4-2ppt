    1. if...else if...else 範例：成績等級判斷

    C++ 範例程式碼 (點擊行號觀看說明)

    1#include <iostream>
    2using namespace std;
    4int main() {

    11cout << "輸入錯誤！分數必須在 0 到 100 之間。" << endl;
    12}
    14else if (score >= 90) {
    15cout << "等級：A (表現優異)" << endl;
    17} else if (score >= 80) {
    18cout << "等級：B (表現良好)" << endl;
    20} else if (score >= 70) {
    21cout << "等級：C (表現尚可)" << endl;
    23} else if (score >= 60) {
    24cout << "等級：D (及格)" << endl;
    26} else {
    27cout << "等級：F (不及格)" << endl;
    28}
    29return 0;
    30}
    💡 提示：點擊上方程式碼任一行，即可看見逐行講解！

    邏輯重點與流程圖

    • 順序檢查： 程式由上往下依次測試條件，只要第一個條件成立就執行該區塊。
    • 命中即跳出： 執行完成立的區塊後，會直接跳過後續所有 else if 與 else。
    • else 備用： 上面條件都不成立時，自動執行 else 備用程式。

    動手做練習 (3 & 4)：閏年 Code Review 與 象限判斷

    練習 3：閏年判斷 4 處錯誤 Code Review

    錯誤 1：語法錯誤（結尾缺分號）

    std::cin >> year ← 缺少 ;

    錯誤 2：運算子錯誤（賦值而非比較）

    year % 400 = 0 ← 應改為 ==

    錯誤 3：邏輯順序錯誤（條件被提前攔截）

    先判斷 % 4 == 0 會導致 100/400/4000 的倍數提前被判定，後續的 else if 永遠執行不到。

    錯誤 4：規則判定錯誤

    講義規則規定「每四千年不閏」，但程式碼中 4000 倍數卻輸出「平年」的邏輯未正確調整優順序。

    練習 4：象限判斷完整 logic 填空

    if (x == 0 && y == 0) cout << "原點";

    else if (x == 0) cout << "y 軸";

    else if (y == 0) cout << "x 軸";

    else if (x > 0 && y > 0) cout << "第一象限";

    else if (x < 0 && y > 0) cout << "第二象限";

    else if (x < 0 && y < 0) cout << "第三象限";

    else cout << "第四象限";

    💡 邏輯解析重點：

    1. 優先排除 (0,0) 原點與兩軸 (x=0 或 y=0)。

    2. 進入四大象限時，x 與 y 皆不為 0，因此最後一個分流可直接用 else 代表第四象限 (x>0, y<0)。
