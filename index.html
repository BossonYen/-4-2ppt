多重分支：if...else if...else 結構介紹

當條件超過兩個以上時，單純的 if...else 無法滿足需求，必須使用 if...else if...else 來依序比對多種可能性[cite: 1]。

1. 語法結構格式

if (條件A) {
    // 當「條件A」成立時執行
} 
else if (條件B) {
    // 當「條件A」不成立，且「條件B」成立時執行
} 
else {
    // 以上所有條件都不成立時執行（可選）
}

3. 範例：輸入成績評定等級（A~F）

#include <iostream>
using namespace std;
int main() {
    int score;
    cout << "請輸入分數 (0-100) :";
    cin >> score;
    
    if (score < 0 || score > 100) {
        cout << "輸入錯誤！分數必須在 0 到 100 之間。" << endl;
    }
    else if (score >= 90) {
        cout << "等級：A (表現優異)" << endl;
    }
    else if (score >= 80) {
        cout << "等級：B (表現良好)" << endl;
    }
    else if (score >= 70) {
        cout << "等級：C (表現尚可)" << endl;
    }
    else if (score >= 60) {
        cout << "等級：D (及格)" << endl;
    }
    else {
        cout << "等級：F (不及格)" << endl;
    }
    return 0;
}

巢狀 if 敘述 (Nested if)

當一個條件成立之後，還要進行第二層甚至更多層的細部條件判斷時，就會用到巢狀 if[cite: 1]。

1. 格式說明

if (條件A) {
    // 當 條件A 為真時執行
    if (條件B) {
        // 當 條件A 與 條件B 皆為真時執行
    } else {
        // 當 條件A 為真，但 條件B 為假時執行
    }
} else {
    // 當 條件A 為假時執行
}

3. 範例：電影院門票優惠計算

#include <iostream>
using namespace std;
int main() {
    int age;
    char hasStudentCard;
    cout << "請輸入您的年齡：";
    cin >> age;
    
    // 第一層：判斷年齡是否符合基本票價條件 (12~64歲)
    if (age >= 12 && age < 65) {
        cout << "請問是否有學生證？(y/n)：";
        cin >> hasStudentCard;
        
        // 第二層巢狀：根據是否有學生證給予不同折扣
        if (hasStudentCard == 'y' || hasStudentCard == 'Y') {
            cout << "符合學生優惠！門票價格為：150 元" << endl;
        } else {
            cout << "一般成人票，門票價格為：250 元" << endl;
        }
    } else {
        // 未滿 12 歲或 65 歲以上
        cout << "符合兒童/敬老特惠！門票價格為：100 元" << endl;
    }
    return 0;
}

⚠️ 學生最易犯錯的 5 大觀念與寫程式陷阱

陷阱一：多重分支條件順序顛倒（邏輯覆蓋錯誤）

在 if...else if...else 中，條件是由上往下依序比對[cite: 1]。如果把範圍大的條件寫在最上面（例如先寫 score >= 60 再寫 score >= 90），那麼 90 分以上的成績會在通過第一關時就被攔截，導致永遠無法執行到 A 等級的判斷。

陷阱二：巢狀結構中大括號配對錯誤導致「懸置 else (Dangling else)」

當有多層 if...else 卻省略大括號時，else 會自動與最近且尚未配對的 if 結合。這常導致邏輯解讀與程式實際執行路徑不一致，強烈建議每一層都要加上 {}。

陷阱三：漏掉預設的最後防線 (缺少 else 分支)

在編寫多重分支時，如果情境並非全面涵蓋，卻漏寫了最後的 else，當所有指定條件皆不成立時，程式會默默略過所有區塊，導致潛在的未預期輸出或變數無初值狀態。

陷阱四：條件區間交疊或不連續（漏失數值區間）

例如想表達 60 到 70 分，卻寫成 score >= 60 與 score < 65 中間留下斷層，導致 65~69 分的分數變成「灰色地帶」無法被正確歸類。

陷阱五：在巢狀條件內重複宣告同名變數

在不同的內層區塊中不小心重複宣告相同名稱的區域變數，導致變數有效範圍（Scope）混淆，編譯器報錯或抓錯資料。
