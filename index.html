現實生活中的決策往往不只「是與否」。本單元帶你掌握 if...else if...else 與 巢狀 if，處理更複雜的多條件判斷！

    1. if...else if...else 範例：成績等級判斷

    C++ 範例程式碼 (點擊行號觀看說明)

    1#include <iostream>
    2using namespace std;
    3
    4int main() {
    5int score;
    6cout << "請輸入分數 (0-100) : ";
    7cin >> score;
    8
    9// 檢查輸入是否合理
    10if (score < 0 || score > 100) {
    11cout << "輸入錯誤！分數必須在 0 到 100 之間。" << endl;
    12}
    13// 由大到小依序判斷
    14else if (score >= 90) {
    15cout << "等級：A (表現優異)" << endl;
    16}
    17else if (score >= 80) {
    18cout << "等級：B (表現良好)" << endl;
    19}
    20else if (score >= 70) {
    21cout << "等級：C (表現尚可)" << endl;
    22}
    23else if (score >= 60) {
    24cout << "等級：D (及格)" << endl;
    25}
    26else {
    27cout << "等級：F (不及格)" << endl;
    28}
    29return 0;
    30}
    💡 提示：點擊上方程式碼任一行，即可看見講解！

    邏輯重點與流程圖

    • 順序檢查： 程式由上往下測試，符合條件即執行。
    • 命中即跳出： 執行完完畢後跳過後續區塊。
    • 預設備用： 若條件都不符合，由 else 處理。

    2. 巢狀 if (Nested if) 範例：門票票價計算

    C++ 範例程式碼 (點擊行號觀看說明)

    1#include <iostream>
    2using namespace std;
    3
    4int main() {
    5int age;
    6char hasStudentCard;
    7
    8cout << "請輸入您的年齡: ";
    9cin >> age;
    10
    11// 第一層 if：先判斷年齡是否符合基本票價條件
    12if (age >= 12 && age < 65) {
    13cout << "請問是否有學生證? (y/n): ";
    14cin >> hasStudentCard;
    15
    16// 第二層 if (巢状)：根據是否有學生證給予折扣
    17if (hasStudentCard == 'y' || hasStudentCard == 'Y') {
    18cout << "符合學生優惠！門票價格為：150 元" << endl;
    19} else {
    20cout << "一般成人票，門票價格為：250 元" << endl;
    21}
    22} else {
    23// 未滿 12 歲或 65 歲 (含) 以上特惠
    24cout << "符合兒童/敬老特惠！門票價格為：100 元" << endl;
    25}
    26return 0;
    27}
    💡 提示：點擊程式碼，拆解「外層與內層」的條件判斷流程。

    巢狀判斷流程圖

    先滿足外層條件，才會進入內層判斷。

    graph TD Start([開始]) --> Outer{12 <= age < 65 ?} Outer -- 否 --> Dis[100元 兒童/敬老特惠] Outer -- 是 --> Inner{有學生證? y/Y} Inner -- 是 --> Stu[150元 學生優惠] Inner -- 否 --> Adult[250元 一般成人票]

    D: sum_sq == c_sq

    E: sum_sq > c_sq
