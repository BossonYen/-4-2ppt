if...else if...else 與巢狀 if 介紹

處理多元條件與複雜邏輯分流的進階技巧

多元條件：為什麼需要 if...else if...else？

💡 回顧：前面學過用 if...else 處理「二分法」選擇（如：及格與不及格）。

⚠️ 痛點：現實情境往往非非黑即白，例如溫控系統（大於 30 度開冷氣、小於 18 度開暖氣、其餘送風）。條件超過兩個時，單純 if...else 不敷使用。

✨ 解法：使用 if...else if...else 結構來完美應付多重可能性！

Q：能否舉出另一個適用於 if...else if...else 來處理的生活情境呢？
提示：例如超商會員等級（VIP、黃金、一般）、或是紅綠燈號誌（紅燈、黃燈、綠燈）。

if...else if...else 語法結構與規則


if (條件A) {
    // 當「條件A」成立時執行
} 
else if (條件B) {
    // 當 A 不成立，且 B 成立時執行
} 
else {
    // 以上所有條件都不成立時執行
}
  • 由上往下比對：依序測試條件，只要第一個成立就執行該區塊。
  • 命中即跳出：執行完成立區塊後，直接跳過後續所有 else if 與 else。
  • 預設備用 (else)：若前面條件全不成立，自動執行 else 內容。

💻 範例：輸入成績判斷等級

👇 將滑鼠移至下方程式碼的不同區域，右側會即時顯示詳細說明！

#include <iostream>
using namespace std;
int main() {
    int score;
    cout << "請輸入分數 (0-100)：";
    cin >> score;
    // 檢查輸入是否合理
    if (score < 0 || score > 100) {
        cout << "輸入錯誤！" << endl;
    }
    // 由大到小依序判斷
    else if (score >= 90) {
        cout << "等級：A" << endl;
    }
    else if (score >= 80) {
        cout << "等級：B" << endl;
    else if (score >= 70) {
        cout << "等級：C" << endl;
    else if (score >= 60) {
        cout << "等級：D" << endl;
    else {
        cout << "等級：F" << endl;
    }
    return 0;
}

巢狀 if 敘述 (Nested if)


if (條件A) {
    // 當條件A為真時
    if (條件B) {
        // A與B皆為真
    } else {
        // A為真，但B為假
    }
} else {
    // 當條件A為假時
}
  • 主要條件 (Outer If)：先檢查最外層條件 A。
  • 次要條件 (Inner If)：唯有當條件 A 成立時，才進入檢查內層條件 B。
  • 邏輯分流：每一層皆可配置獨立的 else 來處理未成立狀況。

💻 巢狀 if 範例：電影院門票優惠計算


int age;
char hasStudentCard;
cout << "請輸入您的年齡：";
cin >> age;

if (age >= 12 && age < 65) { // 第一層：基本票價年齡
    cout << "請問是否有學生證？(y/n)：";
    cin >> hasStudentCard;
    if (hasStudentCard == 'y' || hasStudentCard == 'Y') { // 第二層：學生優惠
        cout << "符合學生優惠！門票價格為：150 元" << endl;
    } else {
        cout << "一般成人票，門票價格為：250 元" << endl;
    }
} else { // 第一層否定
    cout << "符合兒童/敬老特惠！門票價格為：100 元" << endl;
}

結構特點：結合年齡層篩選與身分複查，透過巢狀結構清晰呈現多層次優惠邏輯！

📝 動手做練習 4：座標象限判斷

下方為判斷 (x, y) 座標象限的完整程式碼，運用了 if...else if...else 進行多重排他性區分：


#include <iostream>
using namespace std;
int main() {
    double x, y;
    cout << "請輸入 x, y 座標: ";
    cin >> x >> y;
    if (x == 0 && y == 0) {
        cout << "原點" << endl;
    } else if (x == 0) {
        cout << "y 軸" << endl;
    } else if (y == 0) {
        cout << "x 軸" << endl;
    } else if (x > 0 && y > 0) {
        cout << "第一象限" << endl;
    } else if (x < 0 && y > 0) {
        cout << "第二象限" << endl;
    } else if (x < 0 && y < 0) {
        cout << "第三象限" << endl;
    } else { 
        cout << "第四象限" << endl;
    }
    return 0;
}

總結

  • 多重互斥條件判斷 ➔ 使用 if...else if...else 階梯結構。
  • 階層式、附帶前提條件的過濾 ➔ 使用 巢狀 if (Nested if)。
  • 注意程式碼語法細節（如分號遺漏、指定運算子 = 與比較運算子 == 的區分）。

🔍 閏年程式碼的 4 處錯誤解析報告

錯誤地方說明
std::cin >> year (少分號)第 6 行結尾遺漏分號 ;，會導致編譯錯誤。
year % 400 = 0 (指定運算子誤用)將比較運算子寫成指定運算子 =，應改為雙等號 ==。
邏輯順序錯亂year % 100 == 0 放在 year % 4 == 0 之後會攔截掉所有世紀年，導致 400 的判斷失效。正確應先判斷 400 再判斷 100。
4000 年的閏年規則誤植題目指出「每四千年不閏」，程式碼卻未正確對應其數學排他邏輯。
