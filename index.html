4-2 多重選擇與巢狀結構

現實生活中的決策往往不只「是與否」。本單元帶你掌握 if...else if...else 與 巢狀 if，處理更複雜的多條件判斷！

互動思考：生活中的情境

冷氣溫控：>30°C開冷氣、<18°C開暖氣，其餘送風。你還能想到哪些多條件的生活例子？

    1. if...else if...else 語法結構

    語法格式

    if (條件A) {
    // 當「條件A」成立時執行
} 
else if (條件B) {
    // 當「條件A」不成立，且「條件B」成立時執行
} 
else {
    // 以上條件皆不成立時執行（可選）
}
    • 順序檢查：由上往下比對，命中即跳出。
    • 預設備用：全部不成立時執行 else。

    2. 巢狀 if (Nested if) 敘述

    巢狀結構語法

    if (條件A) {
    // 當 外層條件A 為 True
    if (條件B) {
        // A 與 B 皆為 True
    } else {
        // A 為 True，B 為 False
    }
} else {
    // 外層條件A 為 False
}

    適用於「滿足第一階段條件後，再進行第二階段精細分類」的情境（如門票票價計算）。

    動手做練習 (1 & 2)

    練習 1：三角形判斷填空

    請按按鈕對照填空答案 (A ~ E)：

    A: using namespace std;
    B: a <= 0 || b <= 0 || c <= 0
    C: a + b <= c
    D: sum_sq == c_sq
    E: sum_sq > c_sq

    答案解析：

    A: using namespace std;

    B: a <= 0 || b <= 0 || c <= 0 (檢查邊長合法性)

    C: a + b <= c (兩邊之和須大於第三邊，反向條件)

    D: sum_sq == c_sq (畢氏定理：直角)

    E: sum_sq > c_sq (畢氏定理：銳角)

    動手做練習 (3 & 4)

    練習 3：閏年判斷程式 Code Review (4處錯誤)

    請找出語法與邏輯錯誤：

    1. 語法錯： std::cin >> year 結尾缺少分號 ;

    2. 比較運算錯： year % 400 = 0 為賦值，應為 ==

    3. 邏輯條件順序錯： 較嚴格的條件（% 400, % 4000）放在後面會被第一個 % 4 == 0 提前攔截。

    4. 閏年定義規則錯： 4000的倍數應為平年，400的倍數應為閏年。

    練習 4：象限判斷邏輯

    引導學生思考：透過多重分支遞進，先排除了點在原點與兩軸（x==0 或 y==0）的情況。

    最後剩餘的條件自動進入四大象限判斷！
